## Highlights
- At work, we’ve been building agentic workflows to support our internal Delivery team on various accounting, cash reconciliation, and operational tasks. To better guide that project, I [wrote my own simple workflow tool](https://lethain.com/our-own-agents-our-own-tools/) as a learning project in January. Since then, the [Model Context Protocol](https://modelcontextprotocol.io/introduction) (MCP) has become a prominent solution for writing tools for agents, and I decided to spend some time writing an MCP server over the weekend to build a better intuition. ([View Highlight](https://read.readwise.io/read/01jsff677jdtw3axq7q0mv8z70))
- The output of that project is [library-mcp](https://github.com/lethain/library-mcp), a simple MCP that you can use locally with tools like [Claude Desktop](https://claude.ai/download) to explore Markdown knowledge bases. I’m increasingly enamored with the idea of “datapacks” that I load into context windows with relevant work, and I am currently working to release my upcoming book in a “datapack” format that’s optimized for usage with LLMs. `library-mcp` allows any author to dynamically build datapacks relevant to their current question, as long as they have access to their content in Markdown files. ([View Highlight](https://read.readwise.io/read/01jsff66c1zjyv3fdy4gcy672g))
- More practically, I’ve already experimented with friends writing their CTO onboarding plans with [Your first 90 days as CTO](https://lethain.com/first-ninety-days-cto-vpe/) as a datapack in the context window, and you can imagine the right datapacks allowing you to go much further. Writing a company policy with all the existing policies in a datapack, along with a document about how to write policies effectively, for example, would improve consistency and be likely to identify conflicting policies. ([View Highlight](https://read.readwise.io/read/01jsff5vw8qg16dpc6tcqs3eqh))
- Altogether, I am currently enamored with the vision of useful datapacks facilitating creation, and hope that `library-mcp` is a useful tool for folks as we experiment our way towards this idea. ([View Highlight](https://read.readwise.io/read/01jsff5wy6drpgwvmq50v70fhe))
