## Highlights
- When Meta's 'muse' first launched, like a number of other folks, I asked it to build me a tarball of its filesystem. I had some fun exploring that and have some stuff I should write up.
  Muse feels really well put together. It's not my only agent, but I find myself actually using it. It's especially good at web browsing. It's *much* more willing to work through CAPTCHAs than some of its competitors. Make of that what you will. ([View Highlight](https://read.readwise.io/read/01m437sxfspqxnwhgq94wztxww))
- One of the more interesting bits I found while spelunking is the set of skills muse has access to. A couple days after doing this for the first time, I realized I should ask it to send me daily updates about what changes.
  It looks like they're doing big frequent rebuilds of all the rust code in the repo. They're also doing regular updates to the skills. To get a handle on that, I asked muse to automate a daily check of skill changes and to push those changes into a git repo.
