## Highlights
- Today we're introducing linked billing on the Claude Platform in beta. Third-party platforms, such as coding agents and workflow automation tools, can let their end customers pay for Claude API usage without sharing an API key. End customers keep their existing Anthropic billing and set their own spend limits, and platforms get a simpler, more secure way to offer Claude. ([View Highlight](https://read.readwise.io/read/01m7tw35dj4b79tw3ep6tytx6b))
- Paying for Claude API usage on a third-party platform usually means sharing an API key, which works like a password: anyone who has the key can make requests billed to the customer, so the platform has to keep it safe. ([View Highlight](https://read.readwise.io/read/01m7tw3fhd0b917hgv1cx4tjmf))
- With linked billing, customers link their Claude Platform organization instead, and usage is billed directly to it. No API key changes hands, so platforms have no customer keys to store, encrypt or rotate, and customers’ API keys never leave their organization. ([View Highlight](https://read.readwise.io/read/01m7tw3m86cean9bjeyq5xfq27))
- Platforms can see usage for each linked customer. Customers approve each linked platform, set a spend limit, and can unlink at any time. ([View Highlight](https://read.readwise.io/read/01m7tw3sep4mrt8120be62p0b6))
- **Launch faster.** Anthropic hosts the approval flow and the billing, so there’s no metering or invoicing to build. ([View Highlight](https://read.readwise.io/read/01m7tw3zmj73rtf8sq6p4ksnq3))
- **Understand usage by customer.** Get each linked customer’s request count, token usage and models used in Console, or programmatically with the [Usage and Cost Analytics API](https://platform.claude.com/docs/en/manage-claude/usage-cost-analytics-api) (beta). ([View Highlight](https://read.readwise.io/read/01m7tw41g7nyg0jcbaetrk3md1))
- **Choose who pays.** Decide on each request whether the platform or the end customer pays, so platforms can pass Claude API costs to customers or cover some features themselves by product or instance. ([View Highlight](https://read.readwise.io/read/01m7tw42h50jz4kyw9nsxegh14))
- Customers can easily link to platforms using Anthropic’s hosted flow. They can then draw down from their existing Anthropic commitment, or pay as they go. With linked billing, customers can also: ([View Highlight](https://read.readwise.io/read/01m7tw471ehw8g5n1xt29m85pq))
- Requests run in the platform’s organization, so settings in the customer’s organization, such as IP allowlists, encryption keys, and data retention, don’t apply. ([View Highlight](https://read.readwise.io/read/01m7tw48z5cv12jse40309kbv8))
- Platforms that support linked billing today include Asana, ClickHouse, Factory, Gumloop, Harness, Higgsfield AI, Kilo Code, Linear, Major, Mintlify, Omni, OpenArt, Niteshift, Railway, Ramp, Runlayer, Tessera, Tines, and Warp. ([View Highlight](https://read.readwise.io/read/01m7tw4aw6c3eqng0zank2mwta))
- Linked billing is available today in beta on the Claude Platform. Third-party platforms can add support by creating an app in [Console](https://platform.claude.com/settings/oauth-apps) and following the steps in the [docs](https://platform.claude.com/docs/en/manage-claude/oauth-apps/organization-billing-connections). Claude Platform customers can link their organization from any supported platform, and find platforms that offer linked billing on [Claude Marketplace](https://claude.com/marketplace/agents-products?howYouPay=linkedBilling). ([View Highlight](https://read.readwise.io/read/01m7tw4ht85r81hdgg39xca826))

Linked billing lets them use their existing Claude commitment to power Agentic Work Management in Asana, including AI Studio and AI Teammates, with less setup and spending limits they control as adoption grows.” ([View Highlight](https://read.readwise.io/read/01m7tw4s0b6tdj2y4eq2sa8vr0))
